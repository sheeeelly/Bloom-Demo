# 选品工作台 · AT 智能选品 Demo

静态产品原型，演示 **AT（Atelier）智能选品 MVP** 闭环：

```text
六频道监控 → 三场景选品管理 → 方案（左表单 + 右 AI）→ 审批写选款 → 历史回执 / 落地链路
```

主入口：**[`demo-at-mvp.html`](./demo-at-mvp.html)**（配套 [`demo-at-mvp.css`](./demo-at-mvp.css)）。  
产品合同见仓库根目录 [`PRD-AT智能选品工作台-Demo提需版.md`](../PRD-AT智能选品工作台-Demo提需版.md)、[`PRD-AT智能选品MVP.md`](../PRD-AT智能选品MVP.md)。

> 同目录下的 `app.js` / `styles.css` 为早期通用壳样式与遗留脚本；**当前验收以 `demo-at-mvp.*` 为准**。


## 信息架构

| 入口 | 说明 |
|------|------|
| **总览摘要** | 北极星增量 → KR 护栏 → 平台/落地漏斗 → **五信号**健康度与三场景分布（流行趋势不进五源分母） |
| **监控报告** | 侧栏二级切换六频道 |
| **选品管理** | 纯新款 / 负向改款 / 正向改款；创建方案进入方案页 |
| **方案编辑** | 左：下版单式字段；右：**AI 选款分析**（无独立 AI 菜单） |
| **审批与选款** | 负责人通过/驳回/批注；下方历史回执 |
| **属性映射表** | 侧栏底部「演示数据」下；内部标准属性 ⇄ 竞品叫法 |
| 左下角账号 | 身份（运营 / 负责人 / 管理员）· 品类（仅管理员可切）· 市场 |

### 监控六频道

| 频道 | 要点 |
|------|------|
| 流行趋势 | 元素 / 面料 / 颜色；**不计入五源健康度** |
| 竞品网站 | 动态卡片 + 周报；三行筛选（基础 / 站点多选 / 设计细节）；折扣角标 `{n}% OFF` |
| 广告投流 | 媒体平台多选（Facebook / Instagram / Tik Tok）+ 设计细节 |
| 竞品邮件主推 | Newsletter Hero / 次推 |
| 社媒舆情 | 一期 **人工录入** |
| 站内爆款 | 热榜与正负向改款线索；含设计细节筛选 |

### 选品三场景

| Key | 场景 | Demo 行为摘要 |
|-----|------|----------------|
| `pure_new` | 纯新款 | 排序：热销榜 / 上新时间 / 广告力度；可筛「仅邮件主推」 |
| `form_negative` | 负向改款 | 负反馈证据 + 改款方向卡片 |
| `form_positive` | 正向改款 | 热卖属性榜筛机会 + 底座×叠加 |

卡片仅通栏 **创建方案**（无单独「AI分析」按钮）。

### 审批回执

- 列表：方案 / 场景 / 审批 / `goods_id` / 写入选款 / 更新 / 操作  
- **查看进度**：横向进度条「审批进度 · 落地链路追踪」  
  `成稿 → 提交 → 负责人审批 → 写入选款 → 生管/打版 → 上架动销`  
  （后两步未接通生管时显示「打通生管后可追踪」）  
- 同区可阅驳回建议与负责人批注（运营可读）  
- `generation_source=system_hub_at` 仅后台/BI；审批 UI 不作为推荐理由展示

## 角色与约束（Demo）

| 角色 | 能力 |
|------|------|
| 品类运营 `ops` | 监控、入池、编方案、提交审批、阅回执 |
| 品类负责人 `lead` | 通过 / 驳回（必填原因）/ 批注 |
| 管理员 `admin` | 可切品类（非 AT 标「接入中」）；**不可终审** |

硬边界（与总 PRD 一致）：

- 试点 **AT**；雷达消费 `source_line=atelier`，禁止 BD 洗线  
- 不做日频爬取、社媒全自动、交期大盘、全自动打样上架  
- 禁止用 `recency_proxy` 站统称「热销」

## 技术说明

- 纯 HTML + CSS + 内联 JS，无构建依赖  
- Mock 数据写在 `demo-at-mvp.html` 内（监控 SKU、机会、回执、属性映射等）  
- 工程提需与字段/状态机以 Demo 提需 PRD 为准；真数据对接竞品雷达周频产物、广告、邮件、社媒人工、站内爆款与选款写回
