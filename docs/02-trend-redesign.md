# 趋势改造

用最新的流行趋势改一件衣服，生成新款。

适合这种问题：衣服本身还在，但这一季的结构、面料或图案已经变了。保留衣服的身份，把趋势做进去。

## 操作

1. 定季节和品类。不同品类会换一套趋势包。
2. 勾选 1–3 个趋势芯片。芯片来自当季报告里的 structure、fabric、motif。
3. 放入要改的衣服：用已有灵感图、贴链接，或上传一张图。
4. 看自动写好的提示词。需要的话直接改字。
5. 点「生成新款」，到成品库看结果。

## 系统在做什么

| 步骤 | 代码 |
| --- | --- |
| 季节趋势包 | `data/nybfw_packs/` · `app/services/nybfw_prompt.py` |
| 芯片改写提示词 | `app/services/design_service.py` |
| 上传参考图并开款 | `app/routers/design.py` |
| 出图 | `workflows/fashion_design_api.json` |

趋势包是文本灵感，不在仓库里爬杂志图。参考衣服由操作的人放进来。
